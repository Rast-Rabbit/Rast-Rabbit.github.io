# コンテンツ追加手順

リプレイ・セッションログを追加するときの作業手順。  
どちらも構造は同じで、置き場所と一覧ページだけが違う。

---

## 共通の構造

```
（置き場所）/<フォルダ名>/
├── log_export.html   ← ツール生成（触らない）
├── style.css         ← ツール生成（触らない）
├── images/           ← ツール生成（触らない・ない場合もある）
├── img/              ← ツール生成（触らない・ない場合もある）
└── index.html        ← ★ 自分で作るラッパーページ
```

`log_export.html` は外部ツールが生成したファイルなので直接編集しない。  
ログを再生成したときは `log_export.html` / `style.css` / `images/` / `img/` を上書きするだけ。`index.html` は変更不要。

---

## リプレイを追加する

**置き場所**: `replays/<フォルダ名>/`  
**一覧ページ**: `replays/index.html`

### 手順

1. `.input/<フォルダ名>/` にツール生成ファイルを置いておく（任意）

2. `replays/<フォルダ名>/` フォルダを作り、ファイルをコピーする：
   ```bash
   cp -r .input/<フォルダ名> replays/<フォルダ名>
   ```

3. `replays/<フォルダ名>/index.html` を新規作成：
   ```html
   ---
   layout: default
   title: "ここにタイトル"
   nav: replays
   page_css:
     - /css/log-viewer.css
   ---
   <div class="log-viewer">
     <iframe id="log-frame" src="log_export.html" title="ここにタイトル"></iframe>
   </div>

   <script>
     document.getElementById('log-frame').addEventListener('load', function () {
       var inner = this.contentDocument;
       if (!inner) return;
       var h = inner.querySelector('.header');
       if (h) h.style.display = 'none';
     });
   </script>
   ```

4. `replays/index.html` の `<!-- ここに増やしていく -->` の直前にカードを追加：
   ```html
   <!-- N件 -->
   <article class="log-card">
   <a class="log-link" href="./<フォルダ名>/">
   <div class="log-main">
   <h2 class="log-title">タイトル</h2>
   <p class="log-desc">解説文</p>
   <dl class="meta">
   <div class="meta-item">
   <dt>System</dt><dd>BBT</dd>
   </div>
   <div class="meta-item">
   <dt>Players</dt><dd>ＧＭ：xxx<br/>ＰＬ：xxx　xxx</dd>
   </div>
   <div class="meta-item">
   <dt>Upload</dt><dd><time datetime="YYYY-MM-DD">YYYY-MM-DD</time></dd>
   </div>
   </dl>
   <div aria-label="タグ" class="tags">
   <span class="tag">BBT</span>
   </div>
   </div>
   <div aria-hidden="true" class="log-cta">
   <span>読む</span>
   <span class="arrow">→</span>
   </div>
   </a>
   </article>
   ```

## セッションログを追加する

**置き場所**: `session-logs/<フォルダ名>/`  
**一覧ページ**: `session-logs/index.html`

### 手順

1. 手順2〜3は「リプレイを追加する」と同じ。コピー先を `session-logs/<フォルダ名>/` にすること。

2. `session-logs/<フォルダ名>/index.html` を新規作成：
   ```html
   ---
   layout: default
   title: "ここにタイトル"
   nav: session-logs
   page_css:
     - /css/log-viewer.css
   ---
   <div class="log-viewer">
     <iframe id="log-frame" src="log_export.html" title="ここにタイトル"></iframe>
   </div>

   <script>
     document.getElementById('log-frame').addEventListener('load', function () {
       var inner = this.contentDocument;
       if (!inner) return;
       var h = inner.querySelector('.header');
       if (h) h.style.display = 'none';
     });
   </script>
   ```
   （リプレイとの違いは `nav: session-logs` のみ）

3. `session-logs/index.html` にカードを追加。  
   セッションログカードは `last updated` のmeta-itemも含む場合がある：
   ```html
   <div class="meta-item">
   <dt>last updated</dt><dd><time datetime="YYYY-MM-DD">YYYY-MM-DD</time></dd>
   </div>
   ```

---

## 最後に：トップページの更新履歴を追記する

コンテンツを追加したら **必ず** `index.html` の更新履歴にも記録する。

`index.html` の `<ul class="updates-list">` 内の先頭に追加：

```html
<li><time datetime="YYYY-MM-DD">YYYY-MM-DD</time> リプレイ：タイトル　を追加しました。</li>
```

セッションログの場合は「リプレイ」を「セッションログ」に変える。

## Claude Codeに頼む場合

以下の情報を伝えれば一通りやってくれる：

- 種別（リプレイ or セッションログ）
- `.input/` 内のフォルダ名
- タイトル
- 解説文
- System / Players
- タグ（任意）
